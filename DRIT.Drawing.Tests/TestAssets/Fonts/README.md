# Font fixtures

`Lato-Regular.ttf` is the unmodified Lato Regular font from the
[Google Fonts repository](https://github.com/google/fonts/tree/f3b885d5590e307e02542f1a724cec55d567fdaa/ofl/lato),
at commit `f3b885d5590e307e02542f1a724cec55d567fdaa`. Its copyright notice
and SIL Open Font License 1.1 are in [Lato-OFL.txt](Lato-OFL.txt). It is
used for tests that require Latin letters and real glyph outlines.

`glyphicons-halflings-regular.ttf` is the existing icon-font fixture; it does
not contain the Latin letters required by these text tests.
